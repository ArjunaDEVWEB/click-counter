# Click Counter

A simple click counter built with **HTML, CSS, and JavaScript**.

🌐 **Live Demo:** https://arjunadevweb.github.io/click-counter/

## Features

- Track the number of clicks.
- Lightweight and easy to use.
- Built with vanilla HTML, CSS, and JavaScript.

## Tech Stack

- HTML
- CSS
- JavaScript

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/ArjunaDEVWEB/click-counter.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## Project Structure

